# Девять правок (запрос владельца от 2026-11-01)

> **Исторический план. Ревизия 2026-11-08:** восемь правок реализованы; пункт 8
> частично закрыт позднейшими действиями плагина и круговыми эффектами карты.
> Расширенные формы/оформление/звук остаются в R6.3/R6.4
> [единой дорожной карты](roadmap.md). Пустой чекбокс пункта 8 не означает,
> что визуализации сейчас нет вообще.

Порядок и состав согласованы с владельцем. Каждая правка — отдельный вертикальный срез
с тестами и коммитом. См. также `trigger-playlist-work-plan.md` (предыдущий этап).

- [x] 4. Футер редактора триггера прибит к низу вкладки (sticky, `.trigger-footer`).
- [x] 5. Скрыть/показать нижнюю панель — компактные иконки-шевроны (`IconButton`).
- [x] 1. Триггер «урон/лечение»: поле цели (activator / zone / map) — протокол, ядро, UI шага, тесты.
      Доработка по уточнению владельца: кости попадания (бросок на цель, условие попадания против
      полей цели, урон только при попадании) + ручной режим (запросы бросков управляющему целью,
      кубик у строки статуса, у мастера — отмена запроса и автооткат нанесённого урона).
- [x] 2. Токенам поле disposition (союзник/нейтрал/враг) — протокол, миграция, ядро, форма токена.
- [x] 3. Плейлисты в левом проводнике библиотеки: строки, создание из тулбара, drag&drop треков.
- [x] 6. Баннер «Офлайн-правки» только при конфликтах/ошибках.
- [x] 7. Триггер: режим привязки «одна карта / несколько карт» + мини-превью карты в редакторе.
- [ ] 8. Визуализация атак/заклинаний на карте — отдельный срез после согласования дизайна.
- [x] 9. Клик по токену на карте → лист персонажа; настройки токена — только из списка токенов.

Текущий порядок проверок заменяет правило ниже: после мелкой правки — целевые проверки,
после завершённой серии — полный CI; см. [AGENTS.md](../AGENTS.md).

Историческое правило проверок перед каждым коммитом: `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`,
`cargo test -p dnd-desktop export_bindings` (обновляет `bindings.ts`), полный `cargo test`.
