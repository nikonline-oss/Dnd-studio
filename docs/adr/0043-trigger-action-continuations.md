# ADR 0043: Продолжение триггеров после окна реакции

Статус: принято.

Шаг plugin_action может открыть окно реакции, а его следующие шаги должны
дождаться результата. Раньше они выполнялись сразу. Теперь run_steps сохраняет
PendingTriggerRun в существующем runtime: ID ожидаемого корневого действия,
триггер/версию, карту, персонажа/токен активации, номер следующего шага и переменные.
До 128 ожидающих сценариев; сами действия по-прежнему ограничены стеком и лимитами
шагов. Ни исполняемого кода, ни нового языка сценариев нет.

PluginActionResolved несёт необязательный ID действия. Только авторитетный
результат корня продолжает ожидающий сценарий; результат вложенного Counterspell
не принимается за результат исходного заклинания. Переменные action.completed,
action.countered, action.cancelled и action.invalid имеют значения 0/1.
Существующее when позволяет объявить разные последующие шаги.

При completed/countered сценарий продолжается с сохранённого номера. При отмене
мастером, недопустимом действии, изменении версии/выключении триггера или потере
контекста остаток сценария снимается. Запись удаляется перед продолжением, поэтому
повторная доставка результата не повторяет шаги. Одноразовый триггер отмечается
при первом запуске и не запускается заново при продолжении. Следующее действие
может открыть новое окно и сохранить новое продолжение.

Возобновление идёт после обычной реакции триггеров на первичный intent. Эффекты
возобновлённого сценария не запускают каскад других триггеров, как и прежние
эффекты триггеров. Затем повторно проверяется жизненный цикл поддержки/ожиданий;
новые недопустимые продолжения снимаются. Контекст и переменные хранятся в том же
SQLite JSON и удаляются из всех снимков игроков; мастер получает полный снимок.

Пауза относится к окнам plugin_action. Старые ручные roll-request шаги имеют
свой прежний жизненный цикл и не превращаются автоматически в ожидаемые шаги.
Мастер видит подсказку новых переменных в редакторе триггеров. Продолжение
не предоставляет игроку право редактировать или запускать чужой сценарий.
