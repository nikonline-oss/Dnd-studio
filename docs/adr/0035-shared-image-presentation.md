# 0035. Общий показ изображения

- Статус: Принято (P1, GM-9)
- Дата: 2026-11-02

## Контекст

Мастеру нужен показ одного арта поверх интерфейса игроков. Закрытие на одном клиенте
не должно менять общий показ, а доступ к выбранному ассету не должен раскрывать скрытую
карту или остальную библиотеку. Подключившийся заново игрок должен увидеть текущий показ.

## Решение

`ShowImage { asset_id }` доступен GM/Co-GM, проверяет существование изображения и
исключает аудио. Это LastWriteWins для общего состояния презентации, как управление
общим аудио. Ядро создаёт `PresentedImageDto { id, asset_id, version }`, где `id` — ID
намерения. Повторный показ того же ассета новым намерением — новая презентация.
Версия активного показа увеличивается; после закрытия новый показ начинается с версии 1.

`HideImage { id }` — Checked-intent GM/Co-GM. Проверяются ID и версия активного показа,
поэтому запоздавшее закрытие не может убрать следующую картинку. Оба намерения создают
`ImagePresentationChanged { presentation? }`. Состояние входит в снапшот и сохраняется
в `campaign_meta['campaign.presented_image']` существующими SQL-хелперами. Событие и
проекция пишутся одной транзакцией. Отсутствующий ключ старой кампании означает отсутствие
показа; миграция не нужна. Показ сохраняется при переоткрытии и реконнекте до закрытия GM.

Видимый набор ассетов игроков дополнен только активным изображением. Существующая
реснапшот-фильтрация обновляет доступ при показе/закрытии. Видимость сущностей карт,
токенов, досок и прочих ассетов не изменяется. Смена показа не раскрывает скрытую карту,
даже если выбран её фоновый ассет. После закрытия сервер не отдаёт этот ассет игроку,
если других оснований доступа нет; уже загруженные изображения невозможно «забыть»
на чужом клиенте, и это не механизм отзыва уже раскрытой информации.

## Интерфейс

«Показать игрокам» есть в контекстном меню картинки библиотеки/папки и в инспекторе
токена с изображением. Один полноэкранный оверлей отображает выбранный арт целиком,
без слайдшоу и пользовательских подписей. Для больших карт используются существующие
тайлы, а для обычных изображений — display-ассет. Ошибка загрузки не блокирует закрытие.

Esc и «Закрыть картинку» скрывают оверлей только локально для любой роли и не требуют
соединения. Только GM/Co-GM имеет «Закрыть показ у всех». При локальном закрытии у мастера
остаётся компактная панель управления; игрок не может остановить показ для остальных.
Новый ID/версия показа снова открывает картинку, в том числе тот же ассет. Обычный ресинк
того же показа не отменяет локальное закрытие. Фокус удерживается в открытом оверлее
и возвращается после локального закрытия. Привязка к кампании исключает перенос локального
состояния закрытия на другую кампанию.

## Последствия

Протокол 11: новые intents/event и опциональное поле снапшота. Клиент и сервер обновляются
вместе. Старые кампании читаются без миграции. Новых зависимостей, таблиц, HTTP-маршрутов
и runtime SQL-запросов нет. Закрытие клиентского оверлея — только UI-state, не игровая мутация.

Проверки: все роли, отсутствующие/аудио-ассеты, устаревшее закрытие, доступ только к нужному
ассету, SQLite-проекция и загрузка, реальный WS/HTTP с реконнектом и отзывом доступа;
локальный Esc без намерения, повторный показ, ошибка загрузки и сохранение управления GM.
