# 0006. Каталог плагинов в MVP = подписанный статический индекс

- Статус: Принято
- Дата: 2026-10-20

## Контекст

Пользователям нужен каталог плагинов с установкой в один клик, но сервис маркетплейса (аккаунты, модерация,
хостинг) — отдельный продукт, который не нужен для MVP.

## Решение

- Отдельный репозиторий `dndstudio-plugins`: авторы присылают PR с `.dndplugin`.
- GitHub Actions: валидация манифеста, проверки безопасности, подпись ed25519 ключом проекта (секрет CI),
  публикация архива в Releases, обновление `index.json` (тоже подписан).
- Клиент: каталог, поиск по индексу, карточка, установка/обновление в один клик, проверка подписи и SHA-256.
- Опубликованная версия неизменяема. Отзыв версии — флаг `revoked` в индексе.
- Сервис маркетплейса (аккаунты, рейтинги, отзывы, ручная модерация) — пост-MVP.

## Последствия

- Нулевая стоимость инфраструктуры; модерация = ревью PR.
- Ключ подписи — критичный секрет CI.

## Рассмотренные альтернативы

- Собственный сервис маркетплейса сразу: большой объём работ вне ядра продукта.
- Неподписанный индекс: уязвим к подмене.
