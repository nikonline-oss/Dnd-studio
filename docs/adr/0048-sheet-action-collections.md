# ADR-0048: Применение действий из записей листа

Статус: Принято. Дополняет ADR-0047.

## Причина

Добавляемые пользователем атаки в листе содержали название, бонус и урон, но не были связаны с
исполнителем действий. Отдельные кнопки примеров плагина не применяли эти записи.

## Решение

`mechanics.sheet_actions` объявляет коллекции действий: путь списка, поле названия, разрешённые
шаблоны из `mechanics.actions`, необязательное поле выбора шаблона и явно разрешённые привязки
параметров. Узел layout `{ "type": "action", "collection": "attacks" }` находится внутри строки
соответствующего списка. Он показывает выбор правила и кнопку применения этой строки.

Ядро подставляет параметры из проверенного листа: формулу атаки с `@row.*`, урон, дальность,
радиус и тип урона. Правила попадания, спасбросков, расходов, реакций и эффектов остаются в
шаблоне плагина. Фронтенд не присылает исполняемое определение действия. В `rules_view` ядро
возвращает разрешённое действие вместе с его доступностью и геометрией.

Идентификатор действия из листа содержит коллекцию, индекс и версию персонажа. Изменение или
перестановка записей во время выбора цели делает старый идентификатор недействительным.
После объявления действия его определение сохраняется в `PendingAction.definition`: редакция
листа во время окна реакций не подменяет уже объявленное заклинание. Определение сохраняется
в существующем JSON состояния, включая перезапуск. Смена системных правил отменяет ожидание
через существующую очистку стека. Перед исполнением по-прежнему проверяются права и ресурсы.

Коллекции ограничены 16 определениями, список — 100 строками, набор шаблонов — 32. Привязки
сверяются со схемой листа; формулы разбираются существующим ограниченным языком. Плагины
по-прежнему не исполняют код. Протокол — 20, пример SRD — 0.12.0.

В SRD собственные атаки используют ближний или дальнобойный шаблон, собственный бонус,
урон и дальность. В «Магии» добавляются записи заклинаний с выбором поддерживаемого правила
(Огненный шар или Щит веры); другие правила добавляет плагин.

## Взаимодействие с картой

Клик фиксирует цель/область. Движение указателя больше не меняет её предпросмотр; доступны
повторный выбор и отмена. Подтверждение размещается снизу, чтобы не закрывать центр карты.

Щелчок по токену выбирает его лист. Перемещение начинается перетаскиванием с зажатой ЛКМ,
а намерение отправляется один раз после отпускания. Во время боя отображается маршрут,
вне боя — локальная позиция токена. Esc, потеря фокуса и отпускание за пределами карты
отменяют неподтверждённое движение. Диагональная клетка остаётся одной клеткой маршрута.
