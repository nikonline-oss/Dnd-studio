# ADR-0028: свидетельства TDD

Сценарии взяты из запроса владельца: GM/Co-GM управляют общим звуком, остальные роли
не меняют воспроизведение; пауза и перемотка сохраняют ограниченное состояние;
ссылка на аудио раскрывает метаданные только через видимую запись журнала.

Применён ECC tdd-workflow. RED: сначала добавлены тесты в
`crates/dnd-game-core/tests/library.rs`, затем выполнен
`cargo test -p dnd-game-core --test library --offline` с `CARGO_TARGET_DIR=target/ci`.
Компилятор выдал E0599 (нет `SetSoundPlayback`) и E0609 (нет `position_ms`/`paused`).
Это ожидаемый compile-time RED нового контракта, до изменений рабочего кода.

GREEN, тот же каталог сборки:

| Проверка                                                                               | Команда                                                                                  | Результат |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | --------- |
| Четыре роли; пауза, seek, resume; границы; лимит; старые команды и триггеры; видимость | `cargo test -p dnd-game-core --test library --offline`                                   | 12 passed |
| JSON, версия 7, legacy defaults, контракт intent, TS-снапшот                           | `cargo test -p dnd-protocol --test snapshots --offline`                                  | 6 passed  |
| Приостановленный звук с позицией не сохраняется в проекции SQLite                      | `cargo test -p dnd-db --test queries library_folders_and_sounds_are_projected --offline` | 1 passed  |
| Форматирование трёх крейтов                                                            | `cargo fmt -p dnd-protocol -p dnd-game-core -p dnd-db --check`                           | exit 0    |

Снапшоты обновлены тестом с `INSTA_UPDATE=always`, изменения проверены: версия 7,
новый intent и поля DTO. TS-снапшот сохраняет пробел после `|`, выдаваемый Specta;
`git diff --check` отмечает этот пробел, как и формат существующих строк экспортёра.
Bindings фронтенда затем обновлены тестом `export_bindings` десктоп-крейта.

Для интерфейса RED воспроизвёл отсутствие медиавкладок, склейку строк журнала,
отсутствие встроенного аудио, потерю состояния блокировки autoplay и исчезновение компактного
плеера после переноса файла. Соответствующие Vitest-тесты проходят после исправлений.
Проверены права GM/Co-GM/Player/Spectator, локальный mute без отправки intents,
сохранение позиции при одинаковом снапшоте, восстановление после пропуска событий,
отмена перетаскивания и очистка подсветки вложенных целей.

Процент покрытия не измерялся. Реальная передача pause/seek проверяется интеграционным
`tests/remote.rs` с локальным HTTP/WS-сервером и клиентом игрока. Аудиоустройство и native
WebView в автоматических UI-тестах заменены моками; эти тесты не проверяют качество звука.
