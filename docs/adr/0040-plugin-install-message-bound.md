# ADR 0040: Размер сетевой установки плагина

Статус: принято. Исправление, обнаруженное интеграционным прогоном ADR-0039.

Описание системного плагина с листами и декларациями превысило 64 КБ. Протокол
разрешает PluginDto до 512 КБ, но WebSocket раньше обрывал установку ещё до
валидации: общий транспортный предел был 64 КБ. Поэтому корректный пакет работал
локально, но не устанавливался в сетевой сессии.

У соединения мастера и со-мастера транспортный предел допускает максимум из
настроенного лимита и MAX_PLUGIN_BYTES + 4 КБ для конверта. После разбора больший
предел применяется только к InstallPlugin; обычные сообщения, включая Ping с
лишним заполнением, сохраняют настроенный лимит и закрываются с кодом SIZE при
превышении. У игроков и наблюдателей сам транспорт остаётся на обычном пределе.
Размер PluginDto дополнительно проверяет существующая валидация протокола,
а права установки — ядро. Лимиты частоты и проверка загруженного архива сохраняются.

Проверки: сетевой сценарий установки реального SRD-плагина, затем триггер и
персональные снимки; отдельная регрессия подтверждает, что расширенный транспорт
мастера не обходит предел обычных сообщений. Это не повышение общего лимита чата
или остальных намерений.
