# 0013. Автообновление

- Статус: Принято
- Дата: 2026-10-21

## Контекст

CLAUDE.md §10: автообновление, проверка раз в 24 ч, stable-канал; §9: обновления подписаны minisign.

## Решение

- `tauri-plugin-updater`, логика в Rust (`updater.rs`): первая проверка через 60 с после старта, далее
  каждые 24 ч; ручная проверка — «Справка → Проверить обновления».
- Найденное обновление показывается баннером; установка только по кнопке: кампания сохраняется и
  закрывается, обновление скачивается, подпись проверяется плагином, приложение перезапускается.
- Stable-канал = `releases/latest/download/latest.json` на GitHub: «latest» — последний опубликованный
  не-pre-release релиз. Бета-канал при необходимости — отдельный endpoint позже.
- Конфигурация апдейтера (`pubkey`, `endpoints`, `createUpdaterArtifacts`) живёт только в
  `tauri.release.conf.json`, который подмешивает `release.yml`. В dev-сборке плагин не регистрируется,
  а команды отвечают `updater_disabled` — разработка не требует ключа.
- Релизный workflow отказывается собирать, если подпись или endpoint не настроены (плейсхолдеры).
  Инструкция — `docs/releasing.md`.

## Последствия

- Приватный ключ minisign — критичный секрет: без него нельзя выпустить обновление для установленных копий.
