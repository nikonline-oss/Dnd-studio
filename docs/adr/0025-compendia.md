# 0025. Просмотр компендиев

- Статус: Принято
- Дата: 2026-10-28

## Контекст

CLAUDE.md §12 (P0): «просмотр компендиев». Компендии приходят в пакетах плагинов (`compendia/*.json`,
`docs/plugin-format.md`), загрузчик их уже проверяет, но приложение их не показывало. В компендии может
быть до 10 000 записей с произвольными полями системы.

## Решение

- **Источник — пакет плагина в кампании** (`assets/plugins/<sha256>.dndplugin`, ADR-0023), а не
  состояние игры: снапшот и события не несут тысячи записей. Пакеты адресуются по хэшу, поэтому
  разобранные компендии кэшируются в памяти по SHA-256 и не устаревают.
- Команды десктопа: `compendium_list` (компендии установленных плагинов, число записей) и
  `compendium_entries(plugin_id, compendium_id, query, offset, limit)` — поиск по названию на любом
  языке без учёта регистра, страницами до 500.
- Интерфейс: раздел «Компендии» (GM и игроки), компендий открывается во вкладке — поиск слева, запись
  справа. Запись показывается как Markdown, собранный из её полей одинаково для любой системы
  (ADR-0005): имена полей делаются читаемыми, тексты `{ru, en}` — на языке интерфейса, вложенные
  записи и списки — строками. GM копирует запись в журнал (запись «только мастеру»), дальше она
  правится и открывается игрокам как любая другая.
- Таблицы `compendia`/`compendium_entries` из §6 пока не заполняются: они понадобятся для компендиев,
  созданных в UI (P1).

## Последствия

- В удалённой сессии клиент получает пакеты установленных плагинов от сервера и использует тот же
  загрузчик, поиск и отображение. Правила и компендии установленного пакета доступны всем участникам.
- Перенос монстра на карту токеном и броски из записи — позже.

## Реализация удалённого просмотра (этап 4)

- `GET /api/sessions/{id}/plugins/{sha256}` требует токен участника именно этой сессии и отдаёт
  только пакет, хэш которого есть среди установленных плагинов. Загрузка файла до `install_plugin`
  не открывает его участникам; удаление плагина закрывает новые скачивания.
- Перед разбором клиент проверяет SHA-256, ограничивает размер скачивания 256 МиБ (лимит загрузчика)
  и проверяет безопасный формат `.dndplugin`. Архив кэшируется на диске по хэшу, компендии — в памяти.
  Повреждённый дисковый кэш скачивается заново; подтверждённый кэш читается и без сервера.
- Отсутствующие или повреждённые пакеты не кэшируются как пустые компендии: пользователь получает ошибку
  и может повторить запрос. Чтение/проверка больших архивов выполняются вне потока Tokio.
- События установки/удаления плагина и полный реснапшот обновляют запросы компендиев. Повторный batch
  не вызывает повторное обновление. Ключи списка и страниц включают кампанию и ревизию набора
  `(plugin_id, archive_sha256)`: поздний ответ первой загрузки не возвращает удалённый плагин в UI.
  Ошибка или удаление записи убирает устаревшее содержимое из открытой карточки.
