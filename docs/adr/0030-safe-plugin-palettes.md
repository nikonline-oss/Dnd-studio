# 0030. Безопасные палитры плагинов

- Статус: Принято
- Дата: 2026-10-31
- Скоуп: P1, пункт «безопасные темы» глобального этапа 3

## Контекст

После правок интерфейса продолжается глобальный план. Формат распознаёт theme-плагины,
но не загружает и не применяет их оформление. Произвольный CSS запрещён ADR-0009.

## Решение

Тема содержит `theme.json`: словари `light` и `dark` с цветами разрешённых переменных
`--color-*` из штатной палитры. Значения — только HEX-цвета; имена шрифтов, размеры,
селекторы, выражения, URL и CSS-код не допускаются. Палитру проверяют загрузчик,
игровое ядро при установке и клиент перед применением. Действуют общие лимиты плагинов.

Палитра входит в DTO установленного плагина и распространяется обычным pipeline.
Выбор оформления — настройка конкретного устройства, доступная каждому участнику;
это не изменение кампании и не требует игрового intent. Штатный выбор light/dark/system
сохраняется; system отслеживает оформление ОС. Отсутствующие цвета берутся из штатной темы.

Переключение темы и удаление плагина очищают предыдущие overrides. Закрытие кампании
возвращает штатное оформление. Старый плагин без палитры остаётся читаемым, но не
предлагается как применимая тема. Новый пакет kind=theme требует корректный theme.json.

## Последствия

Новых зависимостей и миграций SQLite не требуется: DTO хранится в существующей проекции
installed_plugins. Поле theme имеет default для старых кампаний. Формат ограничен цветами;
перестройка интерфейса и произвольный CSS в тему не входят.
