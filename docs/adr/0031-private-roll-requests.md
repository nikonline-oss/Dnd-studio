# 0031. Приватные запросы бросков

- Статус: Принято
- Дата: 2026-11-02

## Контекст

Проверка незавершённого ручного режима триггеров выявила передачу всех запросов всем
клиентам с последующим скрытием в UI. Это не соответствует серверной фильтрации §7.

## Решение

GM/Co-GM получают все запросы, игрок — только запросы персонажей, которыми он владеет,
зритель — ни одного. Общая проекция игроков удаляет запросы; персональный снапшот
добавляет только разрешённые конкретному пользователю. В WS-batch запрещённое событие
заменяется на Redacted с сохранением последовательности. Карта владельцев формируется
авторитетным сервером при коммите и никогда не сериализуется в клиентский протокол.

Смена владельца персонажа с запросами вызывает персональный реснапшот. Системное
сообщение о создании запроса отправляется только GM; игрок уведомляется его персональным
событием. Права выполнения дополнительно проверяются ядром по текущему владельцу и версии.

## Последствия

Удаление персонажа отменяет его pending-запросы с повышением версии в том же batch.
Отменённый или уже выполненный запрос повторно бросить нельзя. История запросов не удаляется.

Модель хранения ручных запросов сохраняется. Архитектура остаётся server-authoritative;
фильтрация интерфейса не заменяет авторизацию. Личные уведомления PLR-3 используют только
данные, уже разрешённые этому участнику.
