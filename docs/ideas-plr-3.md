# PLR-3: личные сигналы запроса и хода

Скоуп: P1, явно выбран из `ideas-backlog.md` по запросу владельца. Дата: 2026-11-02.

## Результат

- Личная карточка уведомления появляется при ожидающем броске и ходе принадлежащего игроку персонажа.
- Кнопка броска отправляет существующий `FulfillRollRequest` с версией запроса.
- Переход к ходу открывает карту и выбирает нужный токен.
- Все запросы можно открыть в существующем списке; скрытие карточки ничего не отменяет.
- Новое событие вызывает короткий локальный сигнал, отключаемый участником. Повторный
  рендер того же состояния его не повторяет. Если WebView запрещает autoplay, карточка
  остаётся доступной; звуковое разрешение не блокирует игру.
- Анимация ограничена тремя циклами и отключена при `prefers-reduced-motion`.
- Зрителю не предлагается совершить игровое действие. Чужие запросы фильтруются сервером,
  интерфейс дополнительно проверяет владельца (ADR-0031).

## Границы

Уведомления о личных сообщениях появятся вместе с личным каналом, без симуляции отсутствующей
функции. Постоянные настройки и восстановление состояния после перезапуска — отдельный PLR-12.
Полноэкранные модальные окна и системные уведомления ОС этим срезом не добавляются.

## Проверки

Тесты покрывают выбор только собственных запросов, версионируемое выполнение, отсутствие
повторного сигнала, отключение звука, переход к карте/токену и режим зрителя. Серверные
тесты отдельно проверяют личный снапшот, Redacted в WS-batch и смену владельца.
