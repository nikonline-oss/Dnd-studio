# GM-9: показ изображения игрокам (P1)

GM/Co-GM выбирает «Показать игрокам» в меню картинки библиотеки или папки либо в
инспекторе токена с изображением. Картинка открывается поверх приложения у участников.
Обычные изображения и карты из тайлов отображаются целиком с сохранением пропорций.

Esc закрывает только локальный просмотр. У мастера остаётся небольшая панель для
возврата к картинке и завершения показа у всех. Повторный показ того же файла снова
открывает его. Реконнект получает активный показ; закрытие не раскрывает остальные
данные библиотеки или скрытую карту. Один арт, без слайдшоу и подписей.

Решение — ADR-0035, протокол 11. Новые зависимости и миграции не потребовались.
TDD RED: `target/image-show-red.log` и `target/image-show-ui-red.log`.

GREEN: полный `cargo test --workspace --locked`, Clippy workspace/all-targets,
`cargo fmt --all --check`, TypeScript, ESLint и Prettier прошли. Vitest: 457 тестов
в 71 файле. Дополнительно проверены SQLite-проекция, реальный WS/HTTP, реконнект,
доступ только к показанному ассету и его запрет после завершения показа.
