# PLR-4: лента «Моё»

> Завершённый срез в описанных ниже границах. Результаты проверок относятся
> к моменту реализации. Свежая приёмка — R0 [дорожной карты](roadmap.md)
> от 2026-11-08; приватное общение — отдельная задача R5.3.

P1, запрос владельца от 2026-11-02. Реализация — ADR-0032.

В чате добавлен переключатель «Все / Моё». Лента показывает собственные сообщения,
упоминания и уже существующие сообщения о событиях принадлежащих участнику персонажей.
Она не создаёт дополнительные сообщения для действий, которые раньше не записывались в чат.
Отправка текста и бросков остаётся общей; выбор ленты не делает сообщение приватным.

Новые события используют ID персонажей, старые — только однозначные текущие имена.
Загрузка ранней истории сохраняет общий курсор даже при отсутствии совпадений на странице.
Проверки покрывают собственный sender, переименование, совпадения имён, Unicode-границы,
пунктуацию, переключение лент, страницы без совпадений, сохранение связей и миграцию истории.

Проверено: `cargo fmt --all --check`, Clippy для workspace/all-targets, полный
`cargo test --workspace --locked`, TypeScript и ESLint. Vitest: 442 теста в 69 файлах;
отдельный повтор тестов чата после финальных правок: 16 тестов.
