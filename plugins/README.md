# Плагины, поставляемые с DndStudio

Исходники системных плагинов (CLAUDE.md §8, формат — `docs/plugin-format.md`). Пакет `.dndplugin` —
ZIP из `manifest.json`, `system.json`, `sheet/*.json`, `compendia/*.json`, `assets/`; прочие файлы
(README, атрибуция) в пакет не входят.

| Каталог             | Система                                                                                      | Лицензия                         |
| ------------------- | -------------------------------------------------------------------------------------------- | -------------------------------- |
| `system-srd5`       | SRD 5.2: характеристики, спасброски, навыки, хиты, КД, броски; образцы монстров и заклинаний | CC-BY-4.0 (см. `ATTRIBUTION.md`) |
| `system-generic-d6` | Своя система 2d6 + атрибут, без классов и уровней — доказательство универсальности ядра      | MIT OR Apache-2.0                |
