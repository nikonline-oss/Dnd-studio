# dnd-dice

Dice expression parser and roll engine (P0-нотация ADR-0005).

**Разрешённые зависимости (внутренние):** `dnd-expr` (ссылки на поля). Без I/O; RNG передаётся снаружи.

**Этап реализации:** 2 — Стол

## Нотация (P0)

Выражение — сумма термов со знаками `+`/`-` (первый терм может иметь знак). Пробелы между термами
допускаются.

| Форма        | Пример                                  | Смысл                                                                                                  |
| ------------ | --------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `NdX`, `dX`  | `3d6`, `d20`                            | N костей с X гранями (N по умолчанию 1); `d`/`D`                                                       |
| `d%`         | `d%`, `2d%`                             | d100, сохраняется как `%` в каноничной форме                                                           |
| константа    | `5`                                     | неотрицательное целое; знак — оператор перед ней                                                       |
| поле         | `@str_mod`, `@hp.max`                   | `[A-Za-z_][A-Za-z0-9_]*` через `.`; разрешается вызывающим (`FieldLookup`)                             |
| keep/drop    | `4d6kh3`, `4d6 kl1`, `4d6dh1`, `4d6dl1` | оставить старшие/младшие, выбросить старшие/младшие                                                    |
| преимущество | `1d20 adv`, `d20 dis`                   | бросить 2 раза, взять больший/меньший; только для одной кости, **пробел перед `adv`/`dis` обязателен** |

Модификаторы и `d` регистронезависимы; имена полей — регистрозависимы. Один модификатор на терм.
Keep: `1..=N`; drop: `1..N` (хотя бы одна кость остаётся). При равенстве значений оставляется
(или выбрасывается) более ранняя кость.

## Лимиты (`dnd_dice::limits`)

- длина выражения ≤ 256 символов;
- ≤ 1000 брошенных костей на выражение (`adv`/`dis` считаются за 2);
- 1..=1 000 000 граней;
- константы, значения полей, промежуточные суммы и итог — в пределах ±(2^53−1) (ADR-0016),
  проверяется на каждом шаге.

Ошибки — типизированный `DiceError` (thiserror): синтаксис с байтовым смещением, лимиты, поля, итог.

## API

```rust
let expr = dnd_dice::Expr::parse("1d20 adv + @str_mod")?;
let roll = expr.roll(&fields, &mut rng)?; // fields: impl FieldLookup, rng: impl DiceRng
```

- `Expr` создаётся только парсингом, поэтому всегда удовлетворяет лимитам. Сериализуется serde
  как каноничная строка, десериализация парсит заново.
- `Display` даёт **каноничную компактную форму**: без пробелов (кроме ` adv`/` dis`), `1` перед `d`
  опускается, всё в нижнем регистре: `1d20 + 5` → `d20+5`. Она никогда не длиннее исходного ввода,
  поэтому `parse(display(e)) == e` всегда выполняется в пределах лимита длины. Красивое отображение —
  задача UI по структуре `Roll`.
- `Roll { expression, terms: [TermRoll { sign, subtotal, term }], total }`; для костей — каждое
  значение и флаг `kept`. `subtotal` — значение терма до применения знака.
- Поля разрешаются до первого броска: ошибка поля не расходует RNG.
- `DiceRng { fn next_u64 }` — свой трейт (game-core адаптирует свой `GameRng`); `uniform` —
  несмещённая выборка отбраковкой (после 128 подряд отбракованных значений — `RngExhausted`, защита
  от сломанного источника). `SplitMix64` — детерминированный ГПСЧ для тестов и сидов.

## P1 (не реализовано)

Взрывающиеся кости (`!`), пулы успехов (`10d6>=5`), Fate (`dF`).
